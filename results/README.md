# Analysis results

This directory stores the output files generated by the analysis notebook.

The results can be reproduced by placing the required input files in the `data` directory and running:

- `notebooks/GR_QSAR_model_FAERS_prediction_GitHub_ready.ipynb`

## Expected output files

### Model evaluation

- `nested_cv_results.csv`  
  Performance metrics obtained from the outer folds of nested cross-validation.

- `all_trials.csv`  
  Hyperparameter optimization records from the Optuna trials.

- `02_nested_cv_results.png`  
  Visualization of nested cross-validation performance.

### Final model

- `selected_features.csv`  
  Molecular descriptors selected for the final model.

- `final_qsar_model.pkl`  
  Serialized final model, preprocessing objects, feature selector, and applicability-domain information.

### Applicability domain

- `10b_ad_threshold_comparison.png`  
  Comparison of applicability-domain thresholds.

### Model interpretation

- `03a_shap_beeswarm.png`  
  SHAP beeswarm plot for the final model.

- `03b_shap_importance.png`  
  Mean absolute SHAP importance plot.

- `04_shap_dependence.png`  
  SHAP dependence plots for selected molecular descriptors.

### FAERS drug prediction

- `prediction_results.csv`  
  GR high-affinity classifications, model output scores, and applicability-domain results for FAERS drug structures.

- `06_measured_vs_predicted_cm.png`  
  Confusion matrix comparing measured and predicted affinity classes for drugs with available measured pKi values.

## Notes

The generated files may depend on the software versions and random seeds specified in the notebook. The numerical results reported in the manuscript correspond to the executed version of the notebook included in this repository.
