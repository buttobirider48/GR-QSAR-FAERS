# Input data

Place the following input files in this directory before running the notebook:

- `bindingdb_gr_training_descriptors.csv`
- `faers_drugs_smiles_measured_pki.csv`
- `faers_drugs_prediction_descriptors.csv`

The input datasets are not included in this repository.

Binding affinity data should be obtained from [BindingDB](https://www.bindingdb.org/), and FAERS source data should be obtained from the [FDA Adverse Event Reporting System](https://fis.fda.gov/extensions/FPD-QDE-FAERS/FPD-QDE-FAERS.html). Users are responsible for complying with the applicable terms of use and data-use conditions of the original data sources.

The input files should be prepared according to the procedures described in the accompanying manuscript. File names must match those listed above unless the corresponding paths in the notebook are modified.
